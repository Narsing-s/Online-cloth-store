# Online Cloth Store

A responsive multi-category fashion storefront for men, women, kids, footwear and everyday essentials.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Included
- Responsive storefront and category navigation
- Product search and price sorting
- Product cards, wishlist toggles and shopping bag quantity controls
- Men's, women's and kids' collections
- Slippers/footwear, women's innerwear and boys' innerwear collections
- Demo catalogue and checkout-ready cart summary

## Production integrations still required
The current catalogue is demo content. Connect a database/admin product manager, customer authentication, shipping rules and a payment provider before accepting real orders. Never expose service-role keys in browser code.
